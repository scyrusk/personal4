# Analytics
Self-hosted, cookieless analytics (Plausible-style), stored in the analytics_events table:
* Pageviews are tracked server-side for every successful public HTML GET (AnalyticsTracking concern); paper downloads are tracked as a 'download' event.
* Visitor identity is a daily-rotating hash of (secret, date, IP, user agent) — no cookies, nothing personally identifiable stored, so unique-visitor counts reset each day.
* Bots, admin paths (/admin, /dktest), and authenticated (site-owner) sessions are never tracked.
* Admin dashboard at /admin/analytics (HTTP basic auth via PERSONAL_UN / PERSONAL_PASS): visitors/pageviews chart (hourly for "Today", daily otherwise), traffic sources, top pages / downloads / referrers / campaigns, device / browser / OS breakdowns, a realtime "active now" badge (/admin/analytics/realtime), and CSV export (/admin/analytics/export).
* Daily buckets follow the site's time zone (Eastern, set via config.time_zone).
